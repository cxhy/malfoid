# 译文轻改润色

把已有中文译文改成自然中文小说，同时让每句中文仍能在英文原文找到依据。只改表达，不改故事。

输入是逐段的 `SOURCE`（英文）和 `TARGET`（中文）。输出仍是同样数量的中文段落。`SOURCE` 是忠实性基准，不是重译的起点。

## 工作流

1. **读原文，锁定事实。**
   先读 `SOURCE`，记下事实、数字、专名、术语、限定条件、否定、说话者和语气强度。
   完成标准：能为这一段列出这些锚点，并知道哪些不能动。

2. **诊断译文。**
   逐句对照下面的翻译腔清单，给每句要改的地方标一个具体病症。
   完成标准：每个计划修改的句子都有一个命名的症状；没改的句子是判断后保留，不是漏看。

3. **改写表达。**
   按症状修句子：拆合、换语序、转词性、转主动、去冗余、换口语。
   完成标准：意思、限定、说话者和语气强度不变；段落顺序不变；没有新增原文没有的动作、感官或心理。

4. **过忠实性门。**
   原文→译文：每个事实、数字、限定和说话者都有对应。
   译文→原文：每个中文陈述都有原文依据。
   完成标准：找不到无依据的中文陈述；也找不到漏掉的原文事实。拿不准的歧义保留，不用外部知识替原文补全。

5. **调节奏和对白。**
   读出声。长短句要随观察、判断、冲突变化；对白要像人在现场说话，带身份、关系和当下目的。
   完成标准：读起来像中文小说；对白没有互相汇报已知信息；没有为了顺口把所有人写成同一种腔。

6. **按协议交付。**
   每段一个非空中文 `TARGET`，数量和顺序与输入一致，不合并、不拆分、不加解释。
   完成标准：JSON 的 `targets` 数量等于输入段数，顺序一致，全部非空。

## 翻译腔清单

逐段检查；命中才改，没命中就保留。

- **形合迁移**：`的/而/并/且` 等连接词堆叠，句子靠连接词推进。改成意合短句，让动作和因果关系自己站住。
- **长前置定语**：名词前堆一长串修饰。拆成后置说明、独立短句或分句。
- **的的不休**：一个名词短语里连着多个 `的`。删掉可省的修饰，或改成动词结构。
- **被动滥用**：`被……` 连续出现。施动者不重要或未知时，改成话题—说明或主动句。
- **抽象名词作主语**：`他的到来改变了……`。改成 `他来了，于是……` 这类动作句。
- **状语/定语从句语序**：英文式后置状语、RBD 定语。按中文习惯移到前面或拆开。
- **代词密度过高**：`他/她/它` 反复指同一人。指代清楚时删掉，或换成名字、身份、动作。
- **时态标记生硬**：`将会/已经/正在` 泛滥。中文靠语境和体标记，不逐字搬英文时态。
- **习语硬译**：英文习语按字面搬。换成中文里功能相同的说法；找不到就直说意思，不硬造。
- **对白 tag 直译**：`他说道/她问道`、装饰性动作过多。用 `说/问` 和少量能改变关系的动作。
- **四字成语堆砌**：为了“文雅”连续堆成语。节奏是手段，不是目的；过度归化会抹掉原文风格。

## 忠实性门

- 保留事实、数字、专名、术语、限定条件（`only if`、`may`、`can`）、否定、说话者归属和语气强度。
- 保留原文的比喻、夸张和个人语气的作用；不额外强化，也不淡化。
- 中文陈述必须有原文依据；原文没展开的信息不自行补齐。
- 段落顺序、信息顺序和揭示时点不变。
- 术语表给出的 canonical target 原样保留；不为顺口改专名、称呼层级或敬称。

## 轻改尺度

- 只改有命名症状的句子；能不改就不改。
- 选能修掉症状的最小改动，不顺手重写整段。
- 保留作者句长、语气和叙述习惯；不把所有文本磨成同一种短句腔。
- 单段长度变化控制在约 ±10%；超出时，症状必须足以解释。
- 拿不准时回到忠实性：自由度越低，越克制。
